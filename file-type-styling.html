Display States — Per File Type

Each file type derives two color tokens from its icon palette: typeColor1 (primary) and typeColor2 (secondary). Cards use --type-card-background: typeColor1 and --type-card-font-color: typeColor2 across all states. The bottom bar is invariant: bg #F9FAFB · text #111827 · border-top #E5E7EB.
