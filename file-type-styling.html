Swatch Role Hex RGB Description

border_subtle #E5E7EB rgb(229, 231, 235) Card dividers, sidebar boundaries, and panel borders
border_control #D1D5DB rgb(209, 213, 219) Button outlines (Ghost buttons) and checkbox borders

Section 03
Display Colors
Cards and Panels share a standardized Active color scheme. Each file type has its own Inactive color scheme derived from its icon palette.

Inactive States — Per File Type

The bottom bar is invariant across all file types: bg #F9FAFB · text #111827 · border-top #E5E7EB. Outer container border is always #E5E7EB.
