STYLE 1: BOX-AND-ARROW (Most Common)
================================================================================

Example 1.1: Simple Two-Component Connection
--------------------------------------------------------------------------------
+----------+          +----------+
|  Client  |  ------>  |  Server  |
+----------+          +----------+

Example 1.2: Bidirectional Communication
--------------------------------------------------------------------------------
+----------+          +----------+
|  Client  |  <----->  |  Server  |
+----------+          +----------+

Example 1.3: Hub-and-Spoke Topology
--------------------------------------------------------------------------------
         +--------+
         |  Hub   |
         +--------+
         /    |    \
        /     |     \
   +---+   +---+   +---+
   | A |   | B |   | C |
   +---+   +---+   +---+

Example 1.4: Linear Pipeline
--------------------------------------------------------------------------------
+-------+     +-------+     +-------+     +-------+
| Input | --> | Parse | --> | Process| --> | Output|
+-------+     +-------+     +-------+     +-------+

Example 1.5: Multi-Level Architecture
--------------------------------------------------------------------------------
+----------------+     +----------------+     +----------------+
| Presentation   |     | Business Logic |     | Data Access    |
|     Layer      | --> |     Layer      | --> |     Layer      |
+----------------+     +----------------+     +----------------+
        |                      |                      |
        v                      v                      v
+----------------+     +----------------+     +----------------+
|   UI Service   |     |  Core Service  |     |    Database    |
+----------------+     +----------------+     +----------------+

Example 1.6: Request-Response Pattern
--------------------------------------------------------------------------------
Client                     Server
+--------+                +--------+
|        |   Request      |        |
|        | -------------> |        |
|        |                |        |
|        |   Response     |        |
|        | <------------- |        |
+--------+                +--------+

================================================================================
ANTI-PATTERNS (AVOID THESE)
================================================================================

BAD Example 1: No Structure
--------------------------------------------------------------------------------
Core --> UI --> Runtime

PROBLEM: Too simple, no boxes, insufficient visual structure

BAD Example 2: Unclear Relationships
--------------------------------------------------------------------------------
+------+
| Core |
+------+
+------+
|  UI  |
+------+

PROBLEM: No connectors showing relationships between components

BAD Example 3: Using Wrong Characters
--------------------------------------------------------------------------------
[Core Service] ===> [UI Service]
{Process} ~~~> {Handler}

PROBLEM: Brackets and braces not standard box drawing characters

BAD Example 4: Cluttered and Unclear
--------------------------------------------------------------------------------
+-+-+-+  +++  +-+-+-+
|A|B|C|--|||--|D|E|F|
+-+-+-+  +++  +-+-+-+

PROBLEM: Too dense, hard to read, unclear component boundaries
